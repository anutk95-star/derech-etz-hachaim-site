# דרך עץ החיים — אתר

אתר רב-עמודי, מונע-תוכן. העריכה מתבצעת דרך פאנל חינמי (Pages CMS) ללא קוד.

## איך זה בנוי
- `content/*.json` — כל התוכן הניתן לעריכה (טקסטים, מחירים, תמונות).
- `build.js` — מחולל Node (ללא תלויות) שממיר את התוכן לעמודי HTML.
- `assets/` — תמונות ו-CSS.
- `.pages.yml` — הגדרת שדות העריכה בפאנל (בעברית).
- `netlify.toml` — פקודת הבנייה האוטומטית ל-Netlify.

## בנייה מקומית
```
node build.js
```

## עדכון תוכן (ללא קוד)
עריכה דרך https://pagescms.org — התחברות עם GitHub, בחירת ה-repo הזה, ועריכת השדות.
כל שמירה מפרסמת מחדש את האתר אוטומטית.
